Built for Real Network Engineering

16 enterprise-grade networking tools engineered for precision, speed, and zero fluff.

⚡

Async Port Scanner

Scan 1 to 65,535 ports concurrently with non-blocking sockets, service banner grabbing, live port matrix dots, and CVE risk ratings.

🌐

Interactive Topology Map

Subnet sweep with real-time ARP/ICMP, MAC OUI vendor resolution, and clickable Gateway → Switch → Node interactive SVG diagram.

🛡️

Client VPN & ProtonVPN Detector

Unfragmented MTU clamping tests (1420/1280B DF-bit), LAN service isolation audit, and single-device deep inspection for mobile phones.

📈

ISP Multi-Hop Ping Telemetry

Continuous dual-hop latency tracking, RFC 3550 jitter calculation, packet drop audio alerts, and connection stability scoring (A+ to F).

🚀

Bandwidth & Bufferbloat Speedtest

Measure high-throughput transfer rates (Mbps) alongside loaded latency to benchmark network queue management under heavy load.

📶

Wi-Fi Signal & RF Inspector

Native OS Wi-Fi API integration extracting SSID, BSSID, RSSI attenuation (-dBm), radio channel, 2.4/5GHz band, and physical link rate.

🌍

DNS Swiss Knife & Email Auth

Query 10 record types (A, MX, TXT, SOA, CAA), validate SPF & DMARC policy enforcement, and audit DNSSEC cryptographic signing.

🛑

Malicious DNS Threat Sinkhole

Audit domains against threat-blocking resolvers (Quad9, Cloudflare Security, CleanBrowsing), brand typosquatting, and subdomains.

🗺️

Visual Hop Traceroute

Interactive route timeline diagram with AS numbers, BGP prefixes, transit ISP names, Country/City flags, and bottleneck detection.

🧮

Subnet & VLSM Dynamic Allocator

Interactive 32-bit bitmask editor + VLSM planner: enter department host counts and automatically calculate collision-free subnets.

📦

Packet Crafter with Presets

Dispatch Layer-4 TCP/UDP frames with ASCII or Hex payloads. Includes 1-click templates for HTTP, DNS raw hex, NTP, SSDP, and Redis.

⚡

Wake-on-LAN Saved Inventory

Dispatches UDP magic frames across subnets with a persistent device inventory to remotely power on NAS and workstations in 1 click.

One-Step Double-Click Execution

Runs natively on Windows, macOS, Linux, and Android. No Node.js runtime required.

Windows start.bat

Double-click start.bat. Automatically checks Python, auto-installs missing dependencies via pip, and opens the GUI in your default browser.

macOS start.command / NSK.app

Double-click start.command or drag NSK.app into your Applications folder. Built with native macOS Finder compatibility.

Linux NSK.desktop / ./start.sh

Double-click the NSK.desktop launcher or run ./start.sh in terminal. Preserves native executable permissions.

Android PWA Installable

Access your PC or server's LAN IP from Chrome/Firefox on your Android device and tap Add to Home screen for a native mobile experience.
